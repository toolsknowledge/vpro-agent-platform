# Swagger testing – Follow this exact sequence

Open [FastAPI Swagger](http://localhost:8000/docs?utm_source=chatgpt.com).

## Part 1 – Database and document upload

| Step | API                          | Operation                  |
| ---- | ---------------------------- | -------------------------- |
| 1    | `GET /api/db-health`         | Verify PostgreSQL          |
| 2    | `GET /api/vector-health`     | Verify pgvector            |
| 3    | `POST /api/documents/upload` | Upload the downloaded DOCX |
| 4    | `GET /api/documents`         | Find your document ID      |

## Part 2 – Chunking and embeddings

| Step | API                                         | Operation                      |
| ---- | ------------------------------------------- | ------------------------------ |
| 5    | `POST /api/documents/{document_id}/process` | Generate chunks and embeddings |
| 6    | `GET /api/documents/{document_id}/chunks`   | Inspect chunks                 |

Use the document ID returned in Step 3.

## Part 3 – Semantic search

Use `POST /api/search`.

Test:

```
{
  "query": "What are the main features of Python?"
}
```

Then try:

```
{
  "query": "Explain the role of pgvector in RAG."
}
```

## Part 4 – RAG question answering

Use `POST /api/rag/ask`.

```
{
  "question": "Explain the stages of a RAG pipeline."
}
```

Another test:

```
{
  "question": "What is the difference between Python and Java?"
}
```

## Part 5 – Conversation memory

First create a session using `POST /api/chat/sessions`.

Then use `POST /api/chat`:

```
{
  "session_id": 1,
  "question": "What is Python?"
}
```

Follow-up:

```
{
  "session_id": 1,
  "question": "What are its main features?"
}
```

Use the actual session ID returned by your API, not necessarily `1`.

## Part 6 – LangGraph

Use your React chat interface or the Lesson 8 chat endpoint.

Test in sequence:

1. What is an embedding?
2. Why do we use embeddings?
3. What is cosine distance?
4. Explain its role in semantic search.
5. What is LangGraph?
6. Explain conditional edges.
7. What happens when no relevant document is found?

## Part 7 – Agentic AI tools

Use `POST /api/agent/ask`.

Test 1 – Calculator

```
{
  "question": "Calculate (250 * 4) + 150"
}
```

Expected result: `1150`.

Test 2 – Knowledge search

```
{
  "question": "Search my uploaded document and explain pgvector."
}
```

Test 3 – Multiple tools

```
{
  "question": "Search my uploaded document for RAG and calculate 25 * 40."
}
```

Expected calculation: `1000`.

Test 4 – General question

```
{
  "question": "What is Agentic AI?"
}
```

Recommended: Complete each part before proceeding to the next. This will help identify exactly which API or component needs attention if an error occurs.
